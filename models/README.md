# Model artifacts

This repository currently includes the application source and frontend, but not the trained `.joblib` model binaries. To run real inference, copy the four validated baseline files (`circle.joblib`, `numbers.joblib`, `placement.joblib`, `hands.joblib`) into this folder locally, or supply compatible higher-accuracy trained models and their preprocessing pipelines. Never treat the sample preview as real inference.

Do not commit participant drawings, review records, or personal data.
