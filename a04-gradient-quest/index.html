    Conceptos de este mundo: predicción · resultado real · comparación por categorías · puntuación · función de pérdida · pérdida total y promedio.
    Para la presentación: ¿qué representa la función de pérdida?

    Comparamos el regalo predicho con el regalo real. En este juego definimos una pérdida por categorías: 0 si son idénticos, 1 si comparten categoría y 2 si pertenecen a categorías diferentes. La puntuación de satisfacción es 3 − pérdida. Es una regla educativa diseñada para esta actividad; no es una medida universal de emociones.

    L(predicción, realidad) = 0, 1 o 2
    Pérdida total = suma de las 5 pérdidas
    Pérdida promedio = pérdida total / 5

    Los valores 1, 2 y 3 son positivos; una reacción negativa no equivale a una pérdida negativa. Una pérdida menor indica mayor coincidencia con los resultados reales. La reacción del personaje se refiere a la diferencia entre regalos, no al valor de los familiares.

    Esta máquina evalúa con reglas; no contiene un modelo de IA entrenado ni predice emociones reales. Repetir una partida con las mismas cajas permite usar lo observado, pero no demuestra generalización a datos nuevos. Una nueva Navidad cambia los regalos ocultos.

    Alcance de A04: este módulo explica la pérdida, un componente previo a la retropropagación. Por sí solo todavía no explica todo Backpropagation ni realiza descenso de gradiente; esta pérdida discreta no se deriva para entrenar una red.
